# Typing Works Custom

개인 취향에 맞게 화면을 꾸밀 수 있는 독립형 한국어 타이핑 연습 웹사이트입니다.

## 기능
- 문장 연습, 긴 글 연습, 직접 입력 모드
- 타이핑 속도(WPM), 정확도, 진행률, 경과 시간 표시
- 배경 이미지 업로드 및 제거
- 배경 투명도, 흐림, 어둡기 조절
- 글꼴, 글자 크기, 굵기, 글자 색상, 강조 색상 변경
- 입력창 투명도와 카드 흐림 조절
- 디자인 설정을 브라우저에 자동 저장
- 모바일 화면 지원

## 실행
`index.html` 파일을 브라우저에서 열면 실행됩니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`, `style.css`, `script.js`, `icon.svg`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## 참고
- 이 프로젝트는 기존 Typing Works의 원본 코드가 아닌, 별도로 제작한 타이핑 연습 사이트입니다.
- 업로드한 배경 이미지와 디자인 설정은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기에서는 설정이 유지되지 않을 수 있습니다.
- 배경 이미지는 5MB 이하를 권장합니다.
- 웹 글꼴 연결을 위해 인터넷 연결이 있으면 더 다양한 한글 글꼴이 표시됩니다.
